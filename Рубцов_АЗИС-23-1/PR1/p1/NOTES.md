# Практика 1. Анализ функциональности приложения GNOME Calculator и построение Mind Map

## 1. Объект анализа

| Параметр | Значение |
|---|---|
| Приложение | GNOME Calculator (`gnome-calculator`) |
| Версия | **46.3** (вывод `gnome-calculator --version`; подтверждено окном «О приложении» — `screens/56_about.png`) |
| ОС | Ubuntu 24.04.4 LTS, ядро Linux 6.18.44 |
| Графическая среда | виртуальный X-сервер **Xvfb :99** (1280×900×24), оконный менеджер **Openbox 3.6.1**, композитор `xcompmgr` |
| Язык интерфейса | **русский** (`LANG=ru_RU.UTF-8`, `LANGUAGE=ru`, установлен пакет `language-pack-gnome-ru`). Десятичный разделитель в этой локали — запятая |
| Инструменты | `xdotool 3.20160805.1` (эмуляция клавиатуры/мыши), ImageMagick 6.9.12 (`import` — снимки экрана, `montage` — проверка), Graphviz 2.43.0 (`dot`) |

Все скриншоты — реальные снимки окна запущенного приложения (`import -window root -crop <геометрия окна>`), геометрия окна получалась через `xdotool getwindowgeometry`. Ни один снимок не редактировался.

### Оговорки

1. Приложение запущено в headless-окружении (Xvfb) без полноценного сеанса GNOME. При первом запуске (без сеансовой шины D-Bus) настройки **не сохранялись** — в логе `dconf-WARNING: failed to commit changes to dconf`, переключатели «Формат чисел» не срабатывали. После перезапуска через `dbus-run-session -- gnome-calculator` (скрипт `run_calc.sh`) всё заработало. Скриншоты 48 и 50–57 сделаны после перезапуска, поэтому лента истории на них короче.
2. Курсы валют не загружаются (нет доступа к сети, предупреждения `Cannot use ECB rates`), поэтому конвертация валют не проверялась. Проверена конвертация температуры и угла.
3. У окна нет заголовка оконного менеджера: GTK4/libadwaita рисует собственный заголовок (CSD) с кнопками «Отменить», выбором режима и меню «☰».
4. Ввод `π` через `xdotool type` не сработал (ошибка multi-byte) — символ вводился нажатием экранной кнопки `π`.
5. `xdotool type "-8+3"` требует разделителя `--`, иначе строка трактуется как опция.

## 3. Mind Map

* Исходник: `mindmap.dot` (Graphviz, `dot`, rankdir=LR, шрифт DejaVu Sans).
* Изображение: `mindmap.png`, **3272×2373 px** (120 dpi), альбомная ориентация под A4.
* Структура: центр «Калькулятор GNOME (gnome-calculator 46.3)» → 9 ветвей (Режимы работы, Базовая арифметика, Расширенные функции, Режим программирования, Финансовый режим, История и буфер обмена, Конвертация единиц, Настройки, Справка и навигация) → конкретные функции → тестовые условия (пунктирные узлы). Глубина — 4 уровня.
* Для двусторонней компоновки четыре ветви заданы рёбрами `лист -> группа -> root` (dot размещает их слева от центра), остальные — `root -> группа -> лист`.

Сборка:
```
dot -Tpng -Gdpi=120 mindmap.dot -o mindmap.png
```

## 4. Команды, использованные для снимков

Подготовка окружения:
```bash
apt-get install -y openbox xcompmgr locales language-pack-gnome-ru
locale-gen ru_RU.UTF-8
Xvfb :99 -screen 0 1280x900x24 &
export DISPLAY=:99
openbox &
xcompmgr &                       # композитор, чтобы всплывающие меню рисовались без чёрного фона
./run_calc.sh &                  # LANG=ru_RU.UTF-8 dbus-run-session -- gnome-calculator
WID=$(xdotool search --name '^Калькулятор$' | head -1)
xdotool windowmove $WID 100 60; xdotool windowsize $WID 680 760
```

Скрипт снимка `shot.sh <имя>` (окно ищется по заголовку «Калькулятор», геометрия берётся через `xdotool getwindowgeometry --shell`, затем):
```bash
import -window root -crop ${W}x${H}+${X}+${Y} +repage screens/<имя>.png
```

Ввод (примеры):
```bash
xdotool key Escape; xdotool type --delay 60 "12+7"; xdotool key Return; ./shot.sh 01_basic_add
xdotool type --delay 60 -- "-8+3"                     # унарный минус
xdotool key ctrl+alt+a / ctrl+alt+p / ctrl+alt+f / ctrl+alt+k   # смена режима
xdotool mousemove 360 87 click 1                      # меню режима
xdotool mousemove 404 588 click 1                     # экранная кнопка π
xdotool type --delay 60 "12 and 10"                   # побитовые операции: and / or / xor, 1<<4
xdotool mousemove 537 535 click 1                     # клик по биту 0 в побитовом редакторе
xdotool key ctrl+c ; xdotool type "1+" ; xdotool key ctrl+v      # копирование/вставка
xdotool key ctrl+comma                                # Параметры
xdotool key ctrl+question                             # Комбинации клавиш
xdotool key ctrl+Escape                               # очистка истории
```

Диалоги (Pmt, Параметры, Комбинации клавиш, О приложении) снимались по их собственной геометрии, например:
```bash
import -window root -crop 462x222+209+329 +repage screens/42_fin_pmt_dialog.png
import -window root -crop 640x440+120+220 +repage screens/49_preferences.png
```

Каждый PNG после съёмки открывался и проверялся визуально; неудачные (залипшее всплывающее меню, перехваченный ввод) пересняты.
